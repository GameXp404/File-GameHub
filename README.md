# 🎮 GameHub

Portal game pribadi ala CrazyGames. Berisi 9 game playable + ~14 placeholder.

## Game tersedia
- 💰 Cash King — clicker dengan 4 tema (moneysite/casino/crypto/MLM), prestige, 20 achievement
- 🐍 Snake Classic
- 🔢 2048
- ⭕ Tic Tac Toe (vs AI)
- 🧠 Memory Match
- ✊ Rock Paper Scissors
- 🔨 Whack-a-Mole
- ⚡ Reaction Test
- 🔮 Tebak Angka

## Local development
Buka `index.html` di browser, atau jalankan `GameHub.bat` di Windows.

## Deployment
Static site — bisa di-host di mana saja:
- Netlify Drop (drag folder ke netlify.com/drop)
- GitHub Pages (push ke repo, enable Pages)
- Cloudflare Pages
- Vercel
