📱 Cara Pakai

1. Format ROMGunakan format .cue + .bin (paling kompatibel). Atau .chd (compressed) / .pbp (PSP eboot).
2. Kontrol DefaultArrow keys = D-pad • Z = X (cross) • X = O (circle) • A = Square • S = Triangle • Enter = Start • Shift = Select
3. Save StateKlik tombol Settings (⚙️) di pojok emulator untuk save/load state, control mapping, shader, dll.
4. PerformanceBrowser PC modern (Chrome/Edge) jalan lancar 60fps. Mobile mungkin lag — gunakan PC untuk pengalaman terbaik.
🔧 Tips Lanjutan

BIOS: EmulatorJS otomatis load BIOS embedded SCPH1001 (open source HLE BIOS). Untuk akurasi maksimal, upload BIOS resmi PS1 yang Anda miliki.

Multi-disc games: Untuk game multi-disc (FF7, FF9), ganti disc lewat menu Settings → Disc Control.

Format CHD lebih kecil: Konversi BIN/CUE → CHD pakai chdman (MAME) untuk hemat ~30-50% size.

Memory Card: Save game tersimpan di browser localStorage / IndexedDB. Backup berkala lewat menu Settings → Save State.
