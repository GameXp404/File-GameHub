📌 ROM CD Sendiri (Rip dari Disk Asli)

Kalau Anda punya CD PS1 asli, Anda bisa rip ke file .bin+.cue pakai:
• ImgBurn (Windows, gratis) — Mode → Read → masukin disc → Save
• cdrdao (Linux/Mac) — cdrdao read-cd --device /dev/cdrom out.toc
Hasil rip = legal karena Anda pemilik fisiknya.

🔧 Format ROM & Multi-Disc

Format paling kompatibel: .cue + .bin (pasangan). Upload .cue-nya saja, browser akan minta .bin berikutnya.

CHD (compressed): Konversi BIN/CUE → CHD pakai chdman (MAME tools) untuk hemat 30-50% space.

PBP (PSP eboot): Format Sony resmi PSP, kompatibel langsung.

Multi-disc games (FF7, FF9, Chrono Cross): Ganti disc lewat menu Settings → Disc Control di emulator.

⚡ Performance Tips

• PC modern Chrome/Edge/Firefox: lancar 60fps, bisa fullscreen
• Mobile: bisa lag, recommend pakai PC
• ROM > 200MB: butuh waktu load (browser convert ke memory)
• Save state tersimpan di IndexedDB browser — backup berkala lewat Settings
• Kalau lemot: turunin resolution di Settings → Video → Internal Resolution (1x = original PS1)
